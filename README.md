CodeAlpha Sentiment Analysis

Project Overview

This project performs sentiment analysis on 10,000 tweets using Python and the VADER Sentiment Analyzer.

Dataset

* 5,000 Positive tweets
* 5,000 Negative tweets
* Total: 10,000 tweets

Technologies Used

* Python
* Pandas
* NLTK
* VADER Sentiment Analyzer
* Matplotlib
* Seaborn
* Google Colab

Project Steps

1. Loaded Twitter sample dataset.
2. Combined positive and negative tweets.
3. Calculated sentiment scores using VADER.
4. Classified tweets as Positive, Negative, or Neutral.
5. Visualized results using Pie Chart and Bar Graph.
6. Exported the analyzed dataset as CSV.

Key Findings

* Positive: 5,670 (56.7%)
* Negative: 3,648 (36.5%)
* Neutral: 682 (6.8%)

Conclusion

The project demonstrates how NLP techniques can identify sentiment and understand public opinions from text data.
